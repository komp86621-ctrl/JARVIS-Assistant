# JARVIS-Assistant
JARVIS-Assistant это ассистент который может сильно облегчить вам жизнь (работает даже на очень слабых компьютерах)
## 💻 Системные требования

### 🟢 Минимальные (программа запустится и будет работать)
*   **ОС:** Windows 10 / 11 (только 64-бит)
*   **Процессор:** Любой x64 (например, Intel Core i3 или аналогичный AMD)
*   **Оперативная память:** **4 ГБ** *(Крайний минимум. Возможны небольшие задержки при работе ИИ)*
*   **Место на диске:** ~2 ГБ свободного места (сама программа + кэш голоса)
*   **Звук:** Работающий микрофон и динамики/наушники
*   **Интернет:** Обязателен для работы голоса (Google TTS) и уведомлений PushAll

### 🔵 Рекомендуемые (для максимальной скорости и работы ИИ)
*   **Оперативная память:** **8 ГБ** и выше
*   **Процессор:** 4 ядра и более
*   **Место на диске:** 5 ГБ (если планируете использовать локальный ИИ Ollama)

### ⚙️ Дополнительное ПО (для расширенного функционала)
*   **[Ollama](https://ollama.com/download)** — если хотите, чтобы JARVIS понимал сложные фразы (требует ~2 ГБ ОЗУ при запуске).
*   Модель для Ollama скачивается отдельно командой: `ollama pull qwen2.5:1.5b`
